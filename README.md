# Gold Star Day V1.2 🌱⭐

Replacement build focused on the feedback pass.

## New in V1.2
- Garden-buddy PFP picker on the Today screen
- More decorative, interactive calendar
- Tap calendar dates to see completed habits
- Monthly garden growth indicator
- Fixed habit color editing
- Edit existing habits directly
- Custom color picker
- Rebuilt bottle/jar scene
- Stickers can be placed directly on the bottle
- Challenges now have selectable special sticker rewards
- Completing a challenge unlocks its sticker in the Sticker Book
- Simple custom SVG bug/sticker artwork instead of emoji placeholders
- Migrates V1.1 local data when possible

## Upload
Replace the files in the root of the existing GitHub Pages repository with these files and commit to `main`.
